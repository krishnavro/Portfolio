# Shrikrishna Kumbhar: Portfolio

React + Vite + Tailwind CSS v4.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Where to edit things

| I want to…                              | Edit                                   |
| --------------------------------------- | -------------------------------------- |
| Change any text, link, skill, education | `src/data.js`                          |
| Add a project to "View Other Projects"  | `otherProjects` in `src/data.js`       |
| Add a MERN / Front End project          | `mernProjects` / `frontendProjects`    |
| Replace the photo                       | `src/assets/shrikrishna.jpg`           |
| Change colours or fonts                 | `@theme` block in `src/index.css`      |
| Make the feedback form work             | `handleSubmit` in `src/components/Feedback.jsx` |
| Add a real visitor counter              | `src/components/Footer.jsx`            |
